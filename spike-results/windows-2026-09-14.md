# Windows Architecture Spike Result — 2026-09-14

## Environment

- Operating system: Windows
- Copilot CLI: `1.0.83`
- Integration: repository Hooks enabled for non-interactive prompt mode
- Data: synthetic test assets only

## Verified checkpoints

| Context Egress checkpoint | Observed outcome | Result |
|---|---|---|
| `userPromptTransformed` | Copilot returned `[SECRET_REDACTED]` rather than the synthetic credential. | Pass |
| `postToolUse` | Copilot returned `[PERSON_E34B]` and `[INTERNAL_HOST_E79F]` after reading the synthetic incident report. | Pass |
| `preToolUse` | Copilot reported that the read of `demo/.env` was blocked by a security restriction and did not state file contents. | Pass |

The working behavior confirms the camel-case Hook payload fields used by the adapter are effective for these paths: `transformedPrompt`, `toolArgs`, and successful `toolResult.textResultForLlm`. No raw payload was retained.

## Local hook performance

One hundred independent prompt-hook command invocations were measured locally, including Node startup, JSON input/output, detection, policy decision, placeholder generation, and the content-free receipt:

| Metric | Result |
|---|---:|
| Minimum | 65.8 ms |
| Median | 76.3 ms |
| p95 | 98.1 ms |
| Maximum | 134.0 ms |

The p95 result meets the spike target of less than 300 ms. It excludes Copilot model-response time.

## Scope and Coverage Gaps

- Verified only on Windows with Copilot CLI 1.0.83.
- Verified only the synthetic prompt, one successful file-read result, and one `.env` read path.
- `postToolUse` does not cover failed tool results.
- The silent programmatic CLI mode did not visibly surface the Hook's stderr Protection Receipt; user-visible receipt behavior still needs an interactive-terminal check.
- Hook timeouts are fail-open according to Copilot CLI behavior, so the two-second hook budget must remain measured and explicitly covered in future rollout work.
- No persistent event store or dashboard was built in this spike; local tests verify that the in-memory event shape contains no Raw Prompt, result content, or detected values.

## Verdict

**Go — for the three verified Windows Copilot CLI paths only.**

Proceed to the narrow MVP while preserving the listed Coverage Gaps. Repeat this exact suite on the paid macOS environment before claiming macOS or cross-platform coverage.
